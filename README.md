# Tea Ten Beauty & Spa

Сайт салона Tea Ten Beauty & Spa (Приштина) на Next.js 15 + Tailwind CSS 4.

- Весь контент сайта лежит в одном файле — `content/site.json`.
- Админка `/admin` редактирует этот файл и **коммитит его прямо в GitHub**.
- Vercel видит новый коммит и автоматически пересобирает сайт (примерно минута).
- Заявки на запись уходят в **WhatsApp** — форма собирает сообщение и открывает чат.
- Переключатель языков: **EN · SQ · DE · IT · TR · RU**. Английский — основной,
  остальные языки заполняются в админке и подставляются вместо английского там,
  где перевод есть.

---

## 1. Переменные окружения на Vercel

Project → Settings → Environment Variables (для окружения **Production** и **Preview**):

| Переменная | Значение | Зачем |
|---|---|---|
| `ADMIN_PASSWORD` | `teaten0826` | пароль от `/admin` |
| `ADMIN_SESSION_SECRET` | любая длинная случайная строка | подпись cookie сессии |
| `GITHUB_TOKEN` | personal access token | чтобы админка могла коммитить |
| `GITHUB_REPO` | `SupremeGoogle/teaten` | репозиторий |
| `GITHUB_BRANCH` | `main` | ветка (по умолчанию `main`) |
| `NEXT_PUBLIC_SITE_URL` | `https://ваш-домен` | для превью ссылок в соцсетях |
| `DEEPSEEK_API_KEY` | ключ DeepSeek | автоперевод в админке (необязательно) |

**Токен GitHub.** Проще всего — fine-grained token:
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens →
Generate new token → Repository access: только `SupremeGoogle/teaten` →
Permissions → Repository permissions → **Contents: Read and write**.
Классический токен тоже подойдёт, ему нужен скоуп `repo`.

После изменения переменных Vercel нужно один раз передеплоить проект.

## 2. Как работает админка

1. Открываем `/admin`, вводим пароль.
2. Слева — разделы: бренд и цвета, контакты, меню, первый экран, «о нас»,
   услуги, акции, галерея, отзывы, форма записи, футер.
3. Картинки: кнопка **Choose file** открывает проводник устройства.
   Фото автоматически уменьшается до 1800 px и кладётся в очередь.
4. Кнопка **Publish** отправляет один коммит в GitHub: `content/site.json`
   плюс все новые картинки в `public/uploads/`.
5. Через ~минуту Vercel выкатывает изменения на живой сайт.

Тексты, у которых есть флажки языков (EN / SQ / DE / IT / TR / RU), можно переводить.
Пустой язык = показывается английский вариант.

## 3. Автоперевод (DeepSeek)

Сайт написан по-английски, албанский и русский заполняются нейросетью.

В админке слева есть блок **Translation**:

- галочка «Fill Albanian and Russian automatically when publishing» — перевод
  запускается сам при нажатии **Publish**;
- кнопка **Translate now** — перевести прямо сейчас, не публикуя.

Переводится **только то, что реально изменилось**: поле уходит в перевод, если вы
поправили английский текст или если перевод пустой. Если вы вписали албанский или
русский вариант руками, он останется — пока не изменится английский оригинал.

Без `DEEPSEEK_API_KEY` админка работает как обычно, просто не переводит: сохранение
не ломается, в шапке появляется сообщение «Translation skipped».

Модель — `deepseek-chat`, промпт запрещает менять названия брендов (Clarins,
Circadia, Hydrafacial, Dermalux Flex, OxyGeneo, SkinPen) и цифры.

## 4. Телефон WhatsApp

В админке (раздел «Contact») номер задаётся в международном формате без плюса
и пробелов. `044 158 234` в Косово → `38344158234`.

## 5. Локальная разработка

```bash
npm install
cp .env.example .env.local   # впишите ADMIN_PASSWORD
npm run dev
```

Без `GITHUB_TOKEN` админка сохраняет изменения прямо в файлы на диске — удобно
для локальной правки контента.

## 6. Фотографии

Снимки в `public/gallery/` — со стоков **Unsplash** (лицензия разрешает
коммерческое использование, атрибуция не требуется). Это заглушки: как только
появятся хорошие фото самого салона, замените их в админке — каждая картинка
меняется отдельно, разметка не пострадает.

Логотип в `public/brand/`:
`logo-white.png` (для тёмного футера), `logo-dark.png` (для светлой шапки),
`favicon.png` и `apple-icon.png` — иконки для вкладки браузера,
`logo.png` — исходник.

## 7. Страницы услуг

Главная показывает только карточки категорий. Цены живут на отдельных страницах:
`/services/facial-treatments`, `/services/body-massage`, `/services/nails`,
`/services/brows-lashes`.

Адрес страницы задаётся в админке, в разделе **Services** → категория → поле
**Page address**. Если его поменять, старые ссылки перестанут работать.

Каждая страница собирается статически, поэтому новая категория появится в виде
страницы только после деплоя (то есть после «Publish»).

## 8. Отдельные страницы

| Страница | Адрес | Где редактируется |
|---|---|---|
| Подарочные карты | `/gift-cards` | админка → **Gift cards** |
| Локация | `/location` | админка → **Location** |
| Конфиденциальность | `/privacy` | админка → **Privacy page** |
| Категории услуг | `/services/<slug>` | админка → **Services** |

Пункты меню задаются в разделе **Navigation**: `#about` — якорь на главной,
`/gift-cards` — отдельная страница.

Обе новые страницы можно выключить переключателем в админке — тогда они отдают 404
и пропадают из меню (пункт меню нужно убрать вручную в **Navigation**).

**Видео на странице локации** лежит в `public/video/salon.mp4` (720×1280, H.264,
5,3 МБ) с превью `salon-poster.jpg`. Админка загружает только картинки — чтобы
поменять видео, положите новый файл в `public/video/` через GitHub и укажите путь
в поле **Video file**.

## 9. Политика конфиденциальности

Страница `/privacy`, ссылка стоит в подвале. Текст редактируется в админке в
разделе **Privacy page** — заголовок, дата обновления и любое число блоков.

Текст написан под то, как сайт устроен на самом деле: форма записи ничего не
отправляет на сервер, а открывает WhatsApp с готовым сообщением; в браузере
хранится только выбранный язык; карта Google грузится из iframe. Если поменяете
логику сайта — обновите и этот текст.

**Это юридический документ.** Перед публичным запуском покажите его юристу: я
описал фактическую работу сайта, но не могу отвечать за соответствие всем
требованиям законодательства Косова и GDPR.

```
src/components/          секции сайта
src/components/admin/    админка
src/lib/                 типы, переводы интерфейса, GitHub API, авторизация

src/app/services/[slug]/ страницы с ценами по категориям
src/app/gift-cards/      подарочные карты
src/app/location/        как нас найти
public/video/            видео салона
```
